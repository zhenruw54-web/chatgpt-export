## Code changes

- Safe migration accepts either a direct 65/65 match or a strict 63+2 mapping
  with two local proof records of schema `cgx-v02-shared-alias-proof-v1`.
- The original 65 old index keys, their fingerprint values and their
  timestamps are preserved byte-for-byte in the imported index JSON.
- Only a separate receipt stores the two verified shared aliases.
- Crossed mappings, duplicate IDs, missing keys, mismatched fingerprint /
  updated_at / workspace, and incomplete proofs are rejected.
- The scheduler revalidates the receipt before each export and fails closed
  if either shared key disappears or direct coverage changes.
- Migration popup reads the proof from a local JSON file; it never uploads
  the proof to GitHub or any server.
