## New safety improvements after that report

- `cgx-v02-preview` in `src/content.js`: reads the historical metadata list,
  computes the **same fingerprints and index keys as the actual exporter**,
  compares them to the migrated index, and returns count-only results.
  No ZIP is generated and no incremental index is written.
- `cgx-v02-preview-now` in `src/background.js`: one-click read-only preview
  without enabling scheduling. Requires already verified migration receipt.
- Pilot guard: if changed/new metadata records exceed **10**, scheduler blocks
  with `blocked_large_delta` instead of exporting. An empty/unavailable list
  or invalid preview also blocks export. A 0-change preview generates no ZIP.
- Scheduled-mode storage writes now surface errors instead of swallowing them.
- Status `export_started_download_unverified` deliberately **does not**
  assert the Windows download has completed or V0.1 accepted a ZIP.

## Decision gate

  installation, 63+2 identity import and 0-download preview all complete.
- This is **not V0.2 final PASS**. Subsequent *controlled* testing must cover
  new/modified conversations, ZIP media and manifest, Edge restart behavior,

  not after local disk/V0.1 receipt verification. Until this is addressed,
  do **not** enable daily unattended operation in production.
